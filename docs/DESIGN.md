# CM App Design

Material 3. Source: `lib/app/theme.dart`. No hex codes elsewhere.
Contrast = WCAG 2.x ratio. AA needs 4.5:1 for text.

## Palette

| Token | Light | Dark | Use |
|---|---|---|---|
| `primary` (seed) | `#0F766E` (generated by `ColorScheme.fromSeed`) | generated | buttons, app bar, CM bubbles |
| `AppColors.alert` | `#D97706` | `#D97706` | "needs human" alert banner and row marker |
| `AppColors.onAlert` | `#1C1B1F` | `#1C1B1F` | text on alert |
| `error` | `#B91C1C` | `#FCA5A5` | errors |
| `onError` | `#FFFFFF` | `#450A0A` | text on error |
| `AppColors.facebook` | `#1877F2` | `#1877F2` | Facebook chip |
| `AppColors.onFacebook` | `#000000` | `#000000` | text on Facebook chip |
| `AppColors.whatsapp` | `#25D366` | `#25D366` | WhatsApp chip |
| `AppColors.onWhatsapp` | `#0B3D20` | `#0B3D20` | text on WhatsApp chip |

## Contrast (text on background)

| Pair | Ratio | AA |
|---|---|---|
| `#000000` on Facebook `#1877F2` | 4.96:1 | pass |
| `#FFFFFF` on Facebook `#1877F2` | 4.23:1 | FAIL (brief asked white; black used) |
| `#0B3D20` on WhatsApp `#25D366` | 6.22:1 | pass |
| `#1C1B1F` on alert `#D97706` | 5.38:1 | pass |
| `#FFFFFF` on alert `#D97706` | 3.19:1 | FAIL (not used) |
| `#FFFFFF` on light error `#B91C1C` | 6.47:1 | pass |
| `#450A0A` on dark error `#FCA5A5` | 8.51:1 | pass |
| `#FFFFFF` on seed `#0F766E` | 5.47:1 | pass |

Other scheme roles come from `fromSeed`; Material 3 tonal roles are built for 4.5:1 or more.

## Type scale

Material 3 default `TextTheme`. Use `Theme.of(context).textTheme`. No inline `TextStyle`.

## Spacing

Base unit 4 dp: `AppSpacing.xs` 4, `sm` 8, `md` 16, `lg` 24.

## Brand

- Name: `Z-Smart-CM` (production), `Z-Smart-CM [STG]`, `Z-Smart-CM [DEV]`. Set in `android/app/build.gradle.kts` (`appName` placeholder) and `Strings.appName`.
- Logo files in `assets/logo/`: `icon_1024.png` (icon, launcher source), `wordmark.png` (splash), `microzed.jpeg` (credit logo, 200 px: never show above 72 dp). Originals stay untouched.
- Launcher icon: `dart run flutter_launcher_icons` (config in `pubspec.yaml`). One icon for all flavors, white adaptive background.
- Credit rule: "Développé par" + Microzed logo, semantics label "Développé par Microzed". Splash: 56 dp. Login footer: 28 dp.
- Splash: white page in light and dark mode. Icon scales 0.8 to 1.0 with fade (600 ms), then wordmark fades in. Shown at least 1.0 s after the first frame, then the router leaves as soon as auth is known (`SplashGate` in `lib/app/router.dart`).
- No hold at all when auth is known at first frame, when a push tap is pending, or when `disableAnimations` is on (static logos).
